# ACC Telemetry Dashboard

Логгер и дашборд телеметрии Assetto Corsa Competizione: записывает данные из shared memory игры, отдаёт их через API и рисует интерактивные графики + карту трассы.

## Стек

- `acc_logger.py` — читает shared memory ACC (`pyaccsharedmemory`), пишет в SQLite (`telemetry.db`)
- `api.py` — FastAPI: отдаёт телеметрию, сравнивает круги, дергает Claude API для анализа сетапа
- `static/index.html` — фронтенд: Chart.js графики с синхронным hover-курсором + SVG-карта трассы

## Запуск

1. Установка зависимостей:
   ```bash
   pip install fastapi uvicorn numpy pyaccsharedmemory anthropic
   ```

2. Запусти ACC, встань на трассу (Hotlap/Practice/Race), запусти логгер:
   ```bash
   python acc_logger.py
   ```
   `Ctrl+C` — остановить запись, данные сохранятся в `telemetry.db`.

3. Запусти API-сервер:
   ```bash
   uvicorn api:app --reload
   ```

4. Открой `http://127.0.0.1:8000` в браузере.

## Возможности

- Сравнение двух кругов внутри сессии: время, скорость, руль, газ/тормоз, температура шин, обороты
- Синхронный hover-курсор — наводишь на один график, точки подсвечиваются на всех остальных и на карте
- Карта трассы с цветовой кодировкой по скорости


## Известные ограничения

- Карта трассы доступна только для кругов, записанных после добавления `car_x`/`car_z` в логгер
- `telemetry.db` не коммитится в репозиторий (личные данные заездов) — база создаётся локально при первом запуске логгера
